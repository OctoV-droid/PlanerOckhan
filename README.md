# МАСТЕРСКАЯ v2.9.1 — исправление мобильного раздела «ВУЗ»

Это **исправленная версия 2.9**, сохраняющая модель данных v2.9 и все прежние функции.

## Что исправлено

На телефонах версия 2.9 применяла общее правило `.study-buttons { width: 100% }` к кнопкам внутри двухстрочной карточки работ и списка маленьких шагов. В сочетании с `display:flex` это уменьшало ширину заголовка работы и названий шагов до **0 px**. В браузере русский текст из-за `overflow-wrap:anywhere` переносился по одному символу, растягивая карточки на сотни пикселей по высоте.

В v2.9.1:

- Заголовок работы получил отдельную колонку, не занятую кнопками редактирования и удаления.
- Управляющие кнопки размещены компактно, на мобильных устройствах под заголовком работы.
- Исправлен размер кнопок в списке подзадач, чтобы они не вытесняли названия шагов.
- Уточнены правила переноса длинных названий предметов, работ, сроков и шагов: перенос **по словам** с резервным переносом для очень длинных слов.
- Поле быстрого добавления подзадачи теперь оформлено в стиле приложения и удобнее работает на экранах 320 px.
- Обновлены версии подключённых ресурсов в `index.html` (`?v=291`) и имя кэша PWA в `sw.js` (`masterskaya-static-v2-9-1`) для загрузки новых стилей на телефонах.
- В нижней строке планера отображается **МАСТЕРСКАЯ v2.9.1**: это позволяет удостовериться, что открылась новая версия.

**Данные не конвертируются и не удаляются.** Ключи `localStorage` и формат v2.9 остались прежними. Не меняются логика предметов, статус работ, дедлайны, история активности, привычки и другие разделы.

## Как обновить GitHub Pages / PWA

1. **Перед заменой файлов** открой текущий планер и выбери **«Настройки и копия» → «Скачать JSON-копию»**. Сохрани файл себе, НЕ публикуй его в GitHub.
2. Распакуй архив `MASTERSKAYA_v2_9_1.zip`.
3. Скопируй **все файлы из папки `MASTERSKAYA_v2_9_1`** в корень репозитория GitHub, заменив старые `index.html`, `style.css`, `app.js`, `sw.js` и остальные совпадающие файлы. Не добавляй папку целиком как вложенный каталог.
4. Выполни **Commit → Push** через GitHub Desktop и дождись применения изменений на GitHub Pages.
5. На телефоне открой планер онлайн и обнови страницу. При запуске с иконки PWA закрой и вновь открой приложение, затем, при необходимости, обнови страницу ещё раз. Убедись, что внизу отображается `v2.9.1`.
6. Зайди в **ВУЗ → Работы и долги** и проверь названия работ, подзадачи и кнопки.

Если осталась старая вёрстка, вероятнее всего, приложение загружает старую копию из кэша. Обнови страницу при наличии интернета. **Не выбирай «Очистить данные сайта»**, поскольку это может удалить твой `localStorage` с задачами и журналом. Не переустанавливай PWA до экспорта JSON-копии.

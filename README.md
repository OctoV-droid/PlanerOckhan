# МАСТЕРСКАЯ v2.4 — творческий планер

Личный статический сайт для GitHub Pages: задачи и подзадачи, проекты, ВУЗ, публикации, календарь, **менеджер активности**. Работает как PWA на iPhone, Android и ПК. Не требует сервера и платных сервисов.

## Новое в 2.4

### Подзадачи без дедлайнов

Открой раздел **Задачи** → создай или найди основную задачу → **+ Добавить шаг без срока**. Подзадачи имеют только название и отметку выполнения; редактируются и удаляются отдельно.

- Прогресс основной задачи вычисляется из количества выполненных подзадач (`2/4`, `50%`).
- **У подзадач нет поля даты**. Дедлайн можно установить только у родительской задачи.
- Закрытие основной задачи **не меняет** статусы её шагов; статус основной задачи остаётся отдельным решением.
- Подзадачи не отображаются в календаре как самостоятельные дедлайны.

### Менеджер активности

Новый раздел **Активность** в меню.

- Фильтр: 7 / 30 / 90 дней.
- Первый график: завершённые действия **(+)** и повторно открытые **(−)**.
- Учитывает задачи, подзадачи, опубликованные посты, закрытые работы по ВУЗу. Каждый переход в завершённое состояние — одно событие; возврат в работу — обратное событие.
- Второй график: минуты работы по дням.
- Кнопка **+ Записать рабочую сессию** позволяет указать дату, длительность в минутах, направление, проект и заметку.
- Сводка показывает число завершённых и возобновлённых действий, записанное время, дни активности и разницу с предыдущим периодом аналогичной длины.

**Важно:** дни без записей не считаются регрессом. Повторное открытие задачи — не ошибка и не штраф, это отдельный факт возвращения к работе. Время появляется на графике только если ты записал сессию вручную.

### История и совместимость

История событий начинает собираться **после установки версии 2.4**. У старых задач сохранены статусы, но дата фактического выполнения неизвестна, поэтому она не восстанавливается и статистика за прошлые месяцы не выдумывается.

Сохранён ключ `atelier_planner_v1`, поэтому существующие задачи, публикации, ВУЗ и проекты прежних версий остаются доступны в том же браузере по прежнему адресу. Предыдущие файлы JSON поддерживаются импортом. События активности, подзадачи и сессии входят в новые JSON-копии.

## Как обновить GitHub Pages через GitHub Desktop

1. **На старом сайте** открой «Настройки и копия» и экспортируй резервную JSON-копию (храни приватно, **не коммить её в публичный репозиторий**).
2. Распакуй ZIP из чата.
3. GitHub Desktop → выбрать `PlanerOckhan` → **Repository → Show in Explorer**.
4. Скопируй **сами файлы** из ZIP в **корень** репозитория с заменой: `index.html`, `style.css`, `app.js`, `sw.js`, а также остальные файлы при необходимости.
5. GitHub Desktop → вкладка **Changes** → **Commit to main** → **Push origin**.
6. Подожди GitHub Pages 1–3 минуты и обнови сайт по прежнему адресу: https://octov-droid.github.io/PlanerOckhan/ .

**На iPhone:** обнови сайт в Safari; если иконка с домашнего экрана всё ещё открывает старую версию, закрой приложение, открой сайт Safari онлайн и повторно запусти. Сервис-воркер обновлён до `masterskaya-static-v2-4` для замены закэшированного интерфейса. Если долго остаётся старый интерфейс, можно удалить ярлык с домашнего экрана и добавить его снова, **но сначала экспортируй JSON-копию из установленного приложения**, потому что отдельное хранилище данных может исчезнуть при удалении.

## Ограничения

- Без аккаунтов и облачной синхронизации. `localStorage` хранит личные данные **отдельно в каждом браузере/устройстве**.
- GitHub Pages публикует код сайта, **не твои задачи**.
- Автоматической отправки постов в соцсети пока нет.
- PWA тестировалась в эмуляции Chromium на разных ширинах, **а не в Safari на физическом iPhone**.
- Графики рисуются локальным SVG, без сторонних библиотек и сетевых запросов.
- Не храни конфиденциальные сведения в публичном репозитории и не публикуй резервные JSON-файлы.

## Файлы

`index.html` — каркас страницы и подключение ресурсов; `style.css` — адаптивное оформление; `app.js` — логика и локальные данные; `sw.js`, `pwa.js`, `site.webmanifest` — PWA и офлайн-интерфейс; `favicon.*`, `icon-*`, `apple-touch-icon.png` — значки.

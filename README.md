# МАСТЕРСКАЯ 3.0 — «Порядок вместо списков»

**Релиз:** 29 октября 2026 года. Основа — версия 2.9.3. Статическое приложение для GitHub Pages и мобильных браузеров/PWA.

## Что изменилось

### 1. Мини-архив завершённых задач

- В «Задачах» можно **архивировать отдельную выполненную задачу** кнопкой «↧ Архив», а также **все завершённые задачи сразу** отдельной кнопкой с подтверждением.
- Архивирование означает **скрытие**, а не удаление. Исходная задача остаётся в массиве `tasks` с прежним `id`, `projectId`, `status: "done"`, цветом, заметками и подзадачами. Добавляется только `archivedAt: "ГГГГ-ММ-ДД"`.
- Архив открывается через фильтр «Архив» или компактную панель снизу списка. В нём есть поиск, просмотр шагов и кнопка **«Вернуть»**.
- В «Выполненных» изначально видны только **8 задач**, остальные раскрываются кнопкой. Это работает и **без архивации**, чтобы старые задачи сразу не перегружали экран.
- Список «В работе + планы» не включает выполненные задачи. Другая фильтрация, ручной порядок и редактирование сохранены.
- При редактировании завершённой задачи дата архива сохраняется. Если вернуть архивную задачу в работу, сначала восстанови её в списке архива, а затем поменяй статус.
- **Старые завершённые задачи не архивируются автоматически.** Это сознательная мера: ты сам решаешь, что убрать с экрана.

### 2. Проекты: компактная карточка и независимые раскрывающиеся разделы

- Внутри открытого проекта секции «В работе», «Запланировано», «Выполнено» и «Архив проекта» **по умолчанию закрыты**.
- Заголовки секций показывают количество задач. Можно открыть ровно одну секцию, остальные остаются компактными.
- Архивные выполненные задачи **входят в общее количество и процент завершения проекта**, но не занимают место в разделе «Выполнено». В архиве проекта доступно восстановление.
- Общая сетка карточек проектов, сортировки и цвета из 2.9.3 сохранены.

### 3. Активность: раскрытие по направлениям внутри конкретного дня

- Выбор даты, дневные суммы, цветные графики и рабочие сессии из 2.9.3 сохранены.
- В выбранном дне список действий сгруппирован по проектам, ВУЗу и прочим направлениям; каждая группа **свёрнута** и показывает число событий.
- Аналогично сгруппированы рабочие сессии с суммой времени в заголовке.
- Архивирование НЕ создаёт новые завершения и НЕ меняет старые события `activityLog`, даты и рабочие минуты.

### 4. Обзор: карточки «Требует внимания»

- На главной появились компактные карточки ближайших сдач ВУЗа, долгов, просроченных и важных задач.
- Показываются до 4 наиболее актуальных пунктов. Если у работы есть незавершённый шаг, в карточке видно его название.
- Нажатие на задачу открывает её страницу, на учебную работу — раздел ВУЗа. Это не заменяет уже существующие планы и календарь.

## Совместимость и безопасность

- **Используется прежний ключ `localStorage`: `atelier_planner_v1`.** Формат 2.9.3 импортируется без удаления записей, новые поля необязательны.
- Сохраняются проекты, предметы, работы, посещения, подзадачи, публикации, привычки, рабочие сессии и история активности.
- Сама архивная отметка хранится вместе с задачей, а не в дублирующем списке. Поэтому проценты проектов после архивирования не меняются.
- Сохраняется механизм последней исправной резервной копии `atelier_planner_v1_last_good`. При ошибке записи об архивировании изменения откатываются в оперативном состоянии и показывается предупреждение.
- Историю событий, которых не было в `activityLog` до предыдущих версий, задним числом не воссоздаём.
- Пароли и другие секреты в планере хранить не следует. Синхронизация устройств пока не реализована.

## Как безопасно перейти с 2.9.3

1. **Открой текущий планер** на устройстве с основными данными. В «Настройки и копия» скачай **JSON-копию** и сохрани её в надёжном месте **вне GitHub-репозитория**.
2. Распакуй `MASTERSKAYA_v3_0.zip` и скопируй из внутренней папки **файлы приложения** (`index.html`, `app.js`, `style.css`, `storage.js`, `analytics.js`, `habits.js`, `university.js`, `sw.js`, `pwa.js`, `site.webmanifest` и изображения иконок) в корень существующего репозитория с заменой. `tests/` не требуется загружать.
3. В GitHub Desktop выполни **Commit** и **Push origin**.
4. Открой опубликованный сайт с интернетом, обнови страницу/перезапусти PWA. Внизу должна появиться **МАСТЕРСКАЯ v3.0**.
5. Проверь несколько проектов, университетские записи, активности и привычки. Для проверки архива перемести одну выполненную задачу и верни её обратно. Убедись, что процент проекта не изменился.
6. Только затем при необходимости используй массовое архивирование завершённых задач.

**Не очищай данные сайта и PWA.** На телефоне браузер и установленная PWA могут иметь разные хранилища. Если записи не появились, не начинай вводить новые в пустом приложении: проверь адрес сайта, профиль браузера и сохранённую JSON-копию.

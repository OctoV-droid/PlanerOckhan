# МАСТЕРСКАЯ v2.6 — Университет: расписание и журнал посещаемости

Рабочая статическая PWA-версия творческого планера для GitHub Pages, iPhone/iPad, Android и ПК. Эта сборка сделана **поверх v2.5**, сохранив задачи и подзадачи, порядок задач, проекты, публикации, сессии, учебные долги, активность и iOS-установку.

## Новое в v2.6

Откройте **ВУЗ**: вверху три вкладки **«Посещаемость»**, **«Работы и долги»**, **«Сессии»**.

### Посещаемость и расписание

- **+ Пара в расписание**: дисциплина, день недели, время начала/конца, вид пары (лекция, практика, лабораторная, семинар), преподаватель, примечание и периодичность: еженедельно, по чётным или нечётным неделям.
- Для чётных/нечётных недель заполните поле **«Дата в первой нечётной неделе семестра»**. Подойдёт любая дата в той неделе, которую вуз считает первой нечётной. До заполнения недельные пары с такой периодичностью не показываются.
- **Журнал посещений** отображает пары в диапазоне двух недель, который можно передвигать кнопками **«Ранее»**, **«Текущая неделя»**, **«Позже»**.
- Для каждой пары выбирается статус **«Не отмечено»**, **«Посетил»**, **«Пропустил»**, **«Уважительная причина»** или **«Отменена»**. **Неотмеченная пара НЕ считается пропуском.**
- **+ Разовая пара**: добавляйте отдельные занятия, которых нет в повторяющемся расписании.
- Кнопка **✎** редактирует конкретную запись посещения/заметку. Для пары, которой ещё нет в журнале, создаёт запись.
- Кнопка **+ Работа** сразу заполняет дисциплину и дату пары в форме учебной работы (дедлайн не назначается автоматически).
- Недельный график за шесть недель и таблица по дисциплинам. Посещаемость = посещено / (посещено + пропущено + уважительные) × 100. Отменённые и неотмеченные исключены из расчёта.
- Пары показываются и в общем **Календаре** (на телефоне как список событий).
- Если изменить или удалить повторяющуюся пару из расписания, **ранее отмеченные посещения сохранятся** как исторические записи.

### Старые возможности не потеряны

- **Работы и долги:** дисциплины, курсовые, лабораторные, зачёты, экзамены, статусы, сроки и просрочки.
- **Сессии:** даты сессий, привязанные работы.
- **Задачи:** проекты, подзадачи, перетаскивание и ручная сортировка, редактирование и переход из проекта к задаче.
- **Активность:** учёт времени, графики действий.
- **Публикации:** отдельный контент-план по площадкам.
- **PWA:** иконка на телефоне, офлайн-кэш интерфейса, установка с домашнего экрана.

## Обновление через GitHub Desktop

1. В старой версии откройте **Настройки и копия → Скачать JSON-копию**. Не загружайте её в публичный репозиторий!
2. Распакуйте ZIP.
3. GitHub Desktop → `PlanerOckhan` → **Repository → Show in Explorer**.
4. Скопируйте **все файлы из архива**, включая `app.js`, `style.css`, `index.html` и `sw.js`, в корень репозитория, заменив старые. Не копируйте внешнюю папку как дополнительный уровень.
5. GitHub Desktop → **Commit to main** → **Push origin**.
6. Дождитесь GitHub Pages: <https://octov-droid.github.io/PlanerOckhan/>.
7. При старом интерфейсе сделайте Ctrl+F5, а на iPhone перезапустите PWA и дождитесь обновления кэша. **Не удаляйте иконку с домашнего экрана без экспорта данных**.

## Данные и совместимость

- Ключ локального хранилища не изменён: `atelier_planner_v1`. Старые данные v2.5, проекты, задачи и публикации сохраняются при обновлении в том же браузере и по прежнему адресу.
- Данные помещаются в `localStorage`, **не в публичный репозиторий**. Нет автоматической синхронизации между компьютером и телефоном; перенос возможен через экспорт и импорт JSON, который заменяет данные на целевом устройстве.
- Добавлены поля `timetable`, `attendance` и `universityWeekAnchor`, которые включаются в JSON-резервную копию.
- Не происходит автоматической постановки пропусков, даже если урок уже прошёл. История посещений сохраняет снимок предмета и времени при записи.
- Пока нет привязки к официальному расписанию вуза и уведомлений о парах.

## Технические проверки

- `node --check app.js`: синтаксис проходит.
- Chromium с HTML/CSS/JS, загруженными в память (прямые localhost-переходы в тестовой среде блокируются): проверены добавление расписания, установка отметки, сохранение записи в имитации localStorage, создание учебной работы из пары, переключение вкладок, отображение в календаре и отсутствие ошибок выполнения.
- Проверены мобильные ширины **320, 360, 390, 430, 768 px**: горизонтального переполнения не обнаружено.
- Физический Safari iPhone и установленная PWA не тестировались; на своём устройстве проверьте первую установку и загрузку после обновления.

# МАСТЕРСКАЯ v2.9.2 — сворачиваемые задачи и работы ВУЗа

Обновление v2.9.1 с более компактным интерфейсом. **Формат пользовательских данных не изменён.**

## Что нового

### Задачи
- Подзадачи **свёрнуты при первом открытии** страницы.
- В строке «▸ Подзадачи» показано число выполненных шагов, например **3/8 · 38%**, и короткая полоска прогресса.
- Нажатие на строку «Подзадачи» раскрывает список, заметки и кнопку «+ Добавить шаг»; повторное нажатие сворачивает.
- Каждая задача раскрывается независимо от соседних; после отметки галочки или добавления шага раскрытие сохраняется в текущем сеансе.

### ВУЗ
- Предмет (например, «Железобетонные конструкции») отображает заголовок, статус и **все его работы даже в свёрнутом состоянии**.
- Нажатие на название предмета разворачивает/скрывает дополнительные сведения: преподаватель, сессия, срок и заметки. Работы при этом остаются на экране.
- Работы (ЛР, КР, экзамены) по умолчанию компактные: название, тип, статус, срок и счётчик шагов всегда видны; список шагов скрыт.
- Нажатие на название конкретной работы показывает **только её** подзадачи, добавление шагов, подробные заметки, выбор статуса, а также редактирование и удаление самой работы.
- Независимое раскрытие: можно держать открытой одну работу и не видеть шаги всех остальных.
- Отметка шага НЕ равна сдаче работы, как и раньше.

### Технические детали
- Состояния свёрнутости хранятся только в памяти текущей открытой вкладки, **не в localStorage и не в JSON-резервной копии**. После полной перезагрузки разделы снова будут компактными. Пока вкладка открыта, состояние сохраняется даже после перерисовки при редактировании или отметке.
- Добавлены `aria-expanded` и полноценные клавиатурные кнопки для доступности.
- Сохранены существующие ID записей, история активности, привычки, цвета проектов, фильтры, статусы и механизм резервного копирования.
- Обновлены URL ресурсов `?v=292`, подпись внизу приложения и PWA-кэш `masterskaya-static-v2-9-2`.

## Установка обновления GitHub Pages

1. В работающем планере v2.9.1 нажми **«Настройки и копия» → «Скачать JSON-копию»**. Сохрани резервную копию отдельно. **Не загружай персональный JSON в публичный репозиторий GitHub.**
2. Распакуй ZIP-архив `MASTERSKAYA_v2_9_2.zip`.
3. Скопируй **содержимое** папки `MASTERSKAYA_v2_9_2` в корень репозитория с заменой `app.js`, `style.css`, `index.html`, `sw.js` и прочих файлов. Не вкладывай папку как отдельный подкаталог.
4. Сделай `Commit` и `Push` в GitHub Desktop, дождись обновления GitHub Pages.
5. На телефоне открой планер с интернетом, обнови вкладку (или закрой и открой установленную PWA). Убедись, что внизу появилась **МАСТЕРСКАЯ v2.9.2**.
6. Проверь «Задачи» и «ВУЗ»: по умолчанию шаги скрыты, но счётчики и работы видны.

**Не очищай хранилище сайта и не переустанавливай PWA без JSON-копии.** Задачи хранятся в `localStorage` текущего браузера, а не на GitHub.

## Тестирование

Проверено автоматически в Chromium (эмуляция мобильных экранов):
- `tests/smoke_v292.py`: **26/26** проверок бизнес-логики (создание предметов и работ, шагов, импорт старой структуры, JSON-экспорт, сохранение, статусы, отсутствие JS-ошибок).
- `tests/mobile_v292.py`: **9 размеров** (320, 360, 375, 390, 430, 600, 720, 768, 1024 px), отсутствие горизонтального скролла, читаемость, действия в ВУЗе.
- `tests/disclosure_v292.py`: **6 размеров** (320, 375, 390, 430, 768, 1280 px), независимое раскрытие задач/работ/предметов, компактность, отметки и сохранение состояния раскрытия при перерисовке.
- Синтаксис `app.js` и `sw.js` проверен через `node --check`.

Проверка на реальном телефоне в Яндекс Браузере и в установленной PWA не проводилась. Тесты используют искусственные данные и не затрагивают пользовательский планер.

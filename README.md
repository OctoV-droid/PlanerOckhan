# МАСТЕРСКАЯ v2.3 · iPhone / iPad / iOS

Версия **существующего веб-планера для iPhone и iPad**, работающая также на Windows, Android и компьютерах. Это **PWA**: сайт с поддержкой добавления на домашний экран, а **не нативное приложение из App Store**. Сохраняются разделы «Обзор», «Задачи», «Публикации», «ВУЗ», «Календарь», «Проекты», «Настройки».

## Что улучшено для iOS

- Иконка и название **«МАСТЕРСКАЯ»** на экране «Домой», полноэкранный режим при запуске с ярлыка.
- `viewport-fit=cover`, безопасные отступы `env(safe-area-inset-*)` для вырезов и панели Home Indicator.
- Сенсорные цели в мобильном меню и кнопках от 44 пикселей.
- Поля ввода 16 px на сенсорных устройствах, чтобы Safari не приближал страницу при фокусе.
- Модальные окна с прокруткой и доступными кнопками сохранения на узких экранах.
- Манифест приложения и Service Worker: кэширует **только статические файлы интерфейса**; после первого успешного открытия через интернет сайт может открываться без сети. Пользовательские данные не отправляются на сервер и не входят в офлайн-кэш.
- Резервная копия: на совместимых сенсорных устройствах системное меню «Поделиться», где можно выбрать «Сохранить в Файлы»; если меню не поддерживается — обычное скачивание JSON.
- В настройках добавлена инструкция для iPhone/iPad.

## Как обновить существующий GitHub Pages

1. Открой текущую «МАСТЕРСКУЮ» → «Настройки и копия» → экспортируй JSON с задачами, если записи уже есть. **Не загружай JSON с личными данными в публичный GitHub.**
2. Распакуй этот ZIP.
3. В GitHub Desktop выбери существующий репозиторий **`PlanerOckhan`** → `Repository → Show in Explorer`.
4. Скопируй **все файлы** из папки проекта (не саму папку) в корень репозитория с заменой: `index.html`, `style.css`, `app.js`, `pwa.js`, `sw.js`, иконки, манифест и `README.md`.
5. Сделай `Commit to main`, затем `Push origin`. **Publish repository** повторно нажимать не надо.
6. Подожди завершения деплоя GitHub Pages. Адрес сайта прежний: `https://octov-droid.github.io/PlanerOckhan/`.
7. Если показывается старая версия, перезагрузи страницу Safari; иногда iOS потребуется закрыть ярлык и открыть его снова. При установке новой версии service worker обновит статические файлы при следующем сетевом обращении.

## Установка на iPhone / iPad

1. Открой `https://octov-droid.github.io/PlanerOckhan/` **в Safari**.
2. Нажми кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. Выбери **«На экран Домой»** / **«Добавить на экран Домой»**, затем **«Добавить»**. Если пункт не виден, прокрути меню вниз; конкретные подписи зависят от версии iOS.
4. На экране появится иконка «МАСТЕРСКАЯ». Нажми её, приложение откроется в отдельном окне.
5. Создай тестовую задачу, обнови приложение и проверь, что она сохранилась.

## Важно: данные на iPhone

- Текущий ключ хранилища оставлен **`atelier_planner_v1`**, поэтому при обычном обновлении **на прежнем адресе в прежнем браузере** данные не должны пропасть. Перед обновлением обязательно экспортируй JSON.
- **Safari и версия, установленная на экран «Домой», могут иметь раздельные локальные хранилища**. Если в установленном приложении задачи не появились, это не ошибка обновления: импортируй резервную JSON-копию через раздел «Настройки и копия».
- Для сохранения JSON с iPhone используй «Скачать JSON-копию» → «Поделиться» → «Сохранить в Файлы» (если доступно). Для загрузки — «Восстановить из JSON» и выбери файл в приложении «Файлы».
- **Импорт заменяет все данные текущего экземпляра планера.** Сначала экспортируй его содержимое, если там уже есть записи.
- Данные на компьютере, в Safari и в установленном ярлыке **не синхронизируются**. GitHub Pages хранит код, но не твои задачи.
- При удалении приложения, очистке данных сайтов или автоматической очистке хранилища iOS локальные записи могут быть утрачены. Делай резервные копии.

## Офлайн-режим

После хотя бы одного успешного сетевого открытия service worker загружает интерфейс в кэш. Тогда задачи, уже сохранённые в **локальном хранилище именно этого экземпляра приложения**, можно читать и редактировать без сети. Не гарантируется сохранность при очистке кэша или хранилища iOS. Проверяй офлайн-режим *после* установки и первой загрузки с интернетом.

## Что пока НЕ реализовано

- Нативное приложение iOS в App Store, iCloud-синхронизация, вход по Apple ID.
- Синхронизация компьютера и телефона.
- Пуш-уведомления о зачётах и дедлайнах.
- Автоматическая публикация в соцсетях.

## Проверка

**Статически проверены:** синтаксис JavaScript, наличие ресурсов манифеста и service worker, адаптивные размеры 320 / 360 / 375 / 390 / 430 / 768 / 1365 px в Chromium с сенсорной эмуляцией; навигация, открытие университетской формы и создание записи. **Это не тест на физическом iPhone и не полноценная проверка в Safari/WebKit**: окончательную проверку установки, сохранения/восстановления JSON, клавиатуры и офлайн-режима надо сделать на телефоне.

## Состав файлов

- `index.html` — интерфейс и iOS-метаданные;
- `style.css` — адаптивная верстка, безопасные отступы, элементы управления;
- `app.js` — задачи, университет, контент, локальные данные и экспорт;
- `pwa.js` — регистрация service worker и статус сети;
- `sw.js` — ограниченный офлайн-кэш интерфейса;
- `site.webmanifest` — параметры установки PWA;
- `favicon.svg`, `favicon.ico`, `favicon-32.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` — иконки.

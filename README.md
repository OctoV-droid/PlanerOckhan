# МАСТЕРСКАЯ v2.7 · Журнал посещений и компактный обзор

Обновление планера на GitHub Pages. Сохранены: задачи и подзадачи, ручной порядок задач, проекты, публикации, ВУЗ (работы, долги, сессии), статистика активности, календарь и поддержка PWA на iPhone.

## Что исправлено

### Журнал посещений в разделе «ВУЗ»

- **+ Добавить пару в журнал**: разовое занятие создаётся с датой, предметом, временем и состоянием **«Не отмечено»**. Оно сохраняется сразу, даже если ещё не наступило.
- **Галочка «Посетил»**: включить после пары или снять ошибочную отметку. Снятие галочки **не удаляет занятие**. В отличие от v2.6 состояние «Не отмечено» тоже хранится в JSON и localStorage.
- **«Предстоит»**: так отображаются занятия с будущей датой (или с более поздним временем сегодня). Прошедшие занятия без галочки остаются «Не отмечено», а не автоматически «Пропущено».
- **✎**: редактировать предмет, время, дату, заметки или особое состояние (пропущена / отменена / уважительная причина). **✕**: явно удалить запись. Для периодических пар, заданных в расписании, удаление отметки не удаляет сам шаблон повторения.
- По умолчанию показаны две недели; «Ранее» и «Позже» листают журнал. При создании разовой пары на другую дату журнал автоматически переходит к её неделе. Есть и повторяющееся расписание.
- Если вы уже удалили разовую пару через «Не отмечено» в v2.6, новой версии **не из чего её восстановить**. Возможно восстановление из старой JSON-копии, если она сделана до удаления.

### Главная страница

- Баннер «Идеи, проекты и публикации. Без лишнего шума.» стал компактнее.
- Карточка **«ВУЗ · пары на день»** показывает занятия выбранного дня по времени, сколько отмечено как посещённые, и позволяет **ставить/снимать галочку прямо на главной**.
- День автоматически выбирается текущий, стрелки позволяют посмотреть предыдущий и следующий день. Кнопка «Сегодня» возвращает к текущей дате.
- Записи и отметки из обзора и журнала общие, они не дублируются.

## Обновление через GitHub Desktop

1. На действующем сайте откройте **«Настройки и копия» → Экспорт JSON**. Сохраните файл приватно, не загружайте его в публичный GitHub.
2. Распакуйте ZIP-архив, откройте GitHub Desktop → `PlanerOckhan` → **Repository → Show in Explorer**.
3. Скопируйте **содержимое архива в корень** открытого репозитория с заменой, не вложенную папку `masterskaya_v2_7`.
4. Выполните **Commit to main**, затем **Push origin**.
5. Подождите обновления GitHub Pages и обновите вкладку. Если установлено PWA на iPhone, откройте сайт через Safari, затем полностью закройте и заново откройте приложение. Service Worker использует новый ключ `masterskaya-static-v2-7`.

Адрес опубликованного сайта: `https://octov-droid.github.io/PlanerOckhan/`.

## Данные и совместимость

**Не удаляйте данные браузера.** Как и прежде, задачи и посещения сохраняются в `localStorage` под ключом `atelier_planner_v1`. Код нового приложения читает старый формат v2.6. Хранилища Safari, Chrome и версии с домашнего экрана iPhone могут отличаться. Для переноса нужен экспорт и импорт JSON. Подключения к серверам и автоматической синхронизации нет.

## Файлы

- `index.html` — страница.
- `app.js` — задачи, журнал, логика галочек и обзор.
- `style.css` — адаптивный интерфейс.
- `sw.js`, `pwa.js`, `site.webmanifest`, файлы иконок — PWA и кэширование статических файлов.

Автоматизированные тесты в Chromium проверили: создание занятия без отметки, установку/снятие галочки и сохранение после перезапуска, повторяющееся расписание, блок занятий на главной, переключение дней, работу с данными формата v2.6, сохранение будущего занятия, отсутствие горизонтальной прокрутки на ширинах 320–1280 px. Реальное устройство с iOS/Safari необходимо проверить отдельно.

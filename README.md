# МАСТЕРСКАЯ — творческий планер v2.0

Личный планер для художественных проектов, учёбы, задач и публикаций. Работает как статический сайт **без сервера и аккаунтов**. Подходит для GitHub Pages.

## Что нового в версии 2.0

- Название «МАСТЕРСКАЯ» вместо «АТЕЛЬЕ».
- Вместо светло-жёлтого используется спокойный горчичный акцент.
- Раздел **Учёба**: тема, направление, стадия, процент прогресса, дедлайн, следующий шаг, заметки, журнал занятий и их продолжительность.
- Учебные цели с датами отображаются в календаре. На обзорной странице есть блок активных учебных тем.
- Мобильная версия: основные пункты меню видны без горизонтальной прокрутки; календарь на смартфоне выглядит как список событий; улучшены формы и карточки.
- Сохранён прежний `localStorage`-ключ `atelier_planner_v1`, чтобы данные первой версии могли открыться в новой. Название ключа намеренно **не меняли**.

## Как обновить уже опубликованный проект через GitHub Desktop

1. **Сделай копию данных:** открой свой опубликованный планер, зайди в **«Настройки и копия»** и нажми **«Скачать JSON-копию»**. Сохрани этот файл в надёжной папке. JSON-файл с личными задачами **не загружай в публичный GitHub-репозиторий**.
2. В **GitHub Desktop** выбери локальный репозиторий `PlanerOckhan`.
3. Нажми **Repository → Show in Explorer** (или «Показать в проводнике»).
4. **Скопируй с заменой** файлы из этого обновления в **корень репозитория**:
   - `index.html`
   - `style.css`
   - `app.js`
   - `README.md` (необязательно для работы сайта)
5. Вернись в GitHub Desktop. На вкладке **Changes** должны появиться обновлённые файлы.
6. В поле **Summary** напиши, например, `Мастерская v2: цвет, мобильная версия, учёба`.
7. Нажми **Commit to main**.
8. Затем нажми **Push origin**. Повторно нажимать **Publish repository** не нужно.
9. Через несколько минут открой прежний адрес сайта: `https://octov-droid.github.io/PlanerOckhan/`. Если старая версия осталась в кэше, сделай принудительное обновление страницы **Ctrl + F5**.

### Важное о данных

- **Сам GitHub хранит только файлы сайта.** Задачи, публикации и учебные записи хранятся в `localStorage` браузера.
- При обновлении файлов на **том же GitHub Pages-домене** данные в прежнем браузере должны сохраниться, поскольку ключ хранилища прежний. Резервная копия всё равно обязательна на случай ошибки, очистки данных или смены домена.
- При открытии сайта с телефона данные не синхронизируются с компьютером. Для переноса можно экспортировать JSON с одного устройства и импортировать на другом (импорт **заменяет** записи на текущем устройстве).
- Не храни внутри задач логины, пароли, токены или конфиденциальную информацию.
- Соцсети не подключены и публикации не отправляются автоматически. Здесь ведётся только планирование.

## Раздел «Учёба»

1. Нажми **Учёба → + Новая тема**.
2. Заполни название (например, «Hand-painted текстуры»), направление, следующий небольшой шаг, статус, дату и прогресс.
3. После занятия нажми **+ Занятие**, запиши дату, минуты и чему научился.
4. Время занятий суммируется автоматически; **процент освоения задаётся вручную** в редактировании темы.
5. Если у темы есть дата, она отображается в календаре.

## Структура

```text
PlanerOckhan/
├── index.html   # оболочка интерфейса
├── style.css    # темы и мобильная вёрстка
├── app.js       # логика и локальное сохранение
└── README.md    # этот файл
```

Чтобы быстро поменять основной цвет, ищи в конце `style.css` переменную `--accent` (сейчас `#c69a45`). Название — в `index.html`; для заголовка страницы и панели слева используются разные элементы.

## Локальная проверка

Можно открыть `index.html` в браузере. Вариант для разработчика: открыть папку в VS Code и запустить Live Server. Данные на локальном адресе и на опубликованном GitHub Pages-сайте — разные хранилища.

# МАСТЕРСКАЯ v2.2 — фирменная иконка

Это небольшое обновление поверх v2.1. Функции планера и формат localStorage не изменены.

**Добавлено:** горчичная иконка звезды для вкладки браузера (`favicon.svg`, `favicon.ico`, `favicon-32.png`) и изображения для ярлыка на телефоне (`apple-touch-icon.png`, `icon-192.png`, `icon-512.png`). `site.webmanifest` сообщает название и оформление при добавлении на главный экран. Это не офлайн-приложение: для открытия сайта нужен интернет.

**Обновление через GitHub Desktop:** сделай JSON-копию данных через «Настройки и копия» → открой папку репозитория через `Repository → Show in Explorer` → скопируй **все файлы из этого архива в корень репозитория** (с заменой старых) → `Commit to main` → `Push origin`. Не копируй папку целиком внутрь репозитория. Настройки GitHub Pages менять не нужно.

**Телефон:** открой `https://octov-droid.github.io/PlanerOckhan/`, проверь страницы «Обзор», «Задачи», «Публикации», «ВУЗ», «Календарь», «Проекты» и «Настройки». Добавь тестовую запись, перезагрузи страницу и проверь сохранение. Затем удали тестовую запись. На Android (Chrome) воспользуйся меню ⋮ → «Добавить на главный экран» или «Установить» (если доступно); на iPhone (Safari) — «Поделиться» → «На экран „Домой“».

**Важно:** данные планера хранятся отдельно в localStorage каждого браузера. На телефоне список сначала будет пустым, пока не импортируешь свою JSON-копию. Импорт заменит данные в текущем браузере. Не размещай JSON с личными задачами в публичном GitHub. Обновление иконки не удаляет старые записи на компьютере, если адрес сайта и браузер остались прежними.

При старой иконке в браузере подожди публикации GitHub Pages, затем обнови страницу без кэша или открой приватную вкладку; браузеры кэшируют favicon особенно настойчиво.

# МАСТЕРСКАЯ v2.1 — личный планер

Статический сайт для GitHub Pages: проекты, задачи, публикации и **университетские дела**. Код написан на HTML/CSS/JavaScript без серверной части.

## Что нового в 2.1

Раздел «Учёба» из v2.0 заменён разделом **«ВУЗ»**. Он предназначен для текущих работ в университете, а не для самообразования в Blender.

- **Работы и аттестации:** лабораторная, практическая, курсовая, контрольная, отчёт по практике, зачёт, дифференцированный зачёт, экзамен, другое.
- **Карточка работы:** название, дисциплина, тип, статус, дедлайн, приоритет, сессия, преподаватель, следующий шаг, заметки.
- **Статусы:** «Не начато», «В работе», «Готово к сдаче», «Сдано / ожидаю оценки», «Зачтено / закрыто», **«Долг»**. Статус можно быстро менять непосредственно в карточке.
- **Сессии:** отдельная запись с названием и датами начала/окончания. Работы можно привязывать к определённой сессии.
- **Учёт:** количество долгов, просроченных работ без отметки «Долг», дедлайны на ближайшие 14 дней и количество закрытых работ.
- **Фильтры:** незакрытые, долги и просроченное, зачёты и экзамены, закрытые, все; можно дополнительно отфильтровать по дисциплине.
- **Календарь:** даты университетских работ, начало и окончание сессий, общие задачи и публикации.
- **Обзор:** ближайшие университетские сдачи вместо счётчика тем самообучения.
- Мобильная версия адаптирована под узкий экран.

Пример работы: «Лабораторная № 2», дисциплина «Деревянные конструкции», статус «Долг», срок «30.10.2026». Это пример, **в планер не загружены выдуманные долги или экзамены**.

## Обновление из v2.0 в GitHub Desktop

1. **До обновления** открой действующий сайт → «Настройки и копия» → «Скачать JSON-копию». Храни её на компьютере, а не в публичном репозитории.
2. Распакуй архив v2.1.
3. В GitHub Desktop выбери репозиторий `PlanerOckhan` → **Repository → Show in Explorer**.
4. Замени в **корневой папке репозитория** файлы `index.html`, `style.css`, `app.js` и `README.md` файлами из архива. Не нужно создавать новую папку `masterskaya_v2_1` внутри репозитория.
5. Вернись в GitHub Desktop → вкладка **Changes** → проверь изменения.
6. Сообщение коммита: `v2.1: ВУЗ, долги, курсовые и сессии` → **Commit to main** → **Push origin**.
7. GitHub Pages обновится по старому адресу сайта. При необходимости подожди несколько минут и выполни `Ctrl+F5`.

Повторно публиковать репозиторий (**Publish repository**) и менять настройки GitHub Pages не нужно.

## Сохранность данных при обновлении

Сохранён исходный ключ браузерного хранилища `atelier_planner_v1`. Существующие задачи, публикации, проекты и цели по соцсетям остаются на месте **при условии, что сайт открывается по прежнему адресу в том же браузере, а данные не очищены**.

Темы самообучения старой версии (`study`) **сохраняются как архив**. Их названия видны в разделе «Настройки и копия», полные данные остаются в экспортируемом JSON. Они намеренно не смешиваются с учебными предметами университета.

JSON-резервные копии старой и новой версии можно восстановить кнопкой импорта. Импорт **заменяет** текущие данные целиком. Перед импортом сделай ещё одну копию.

## Ограничения

- Данные хранятся **в localStorage браузера**. GitHub Pages предоставляет только интерфейс. Между телефоном и компьютером пока нет автоматической синхронизации.
- Приложение **не публикует контент автоматически** и не подключает аккаунты соцсетей.
- Пока нет push-уведомлений о сроках сдачи. Даты видны в планере и календаре.
- Не сохраняй в заметках пароли, персональные идентификаторы, конфиденциальные оценки или другие чувствительные сведения, особенно если делишься экспортом JSON.
